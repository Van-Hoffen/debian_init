# tmux: настройки и горячие клавиши

Файл `files/home/.tmux.conf` устанавливается в `~/.tmux.conf` и перезаписывается
при обновлении проекта. Старая версия сохраняется как `~/.tmux.conf.~N~`.
Личные настройки держите в `~/.tmux.local.conf` — он подключается последним и
может переопределить любую опцию.

Требования:

- tmux 3.2 или новее (`display-popup`, `new-session -e`);
- пакет `procps` — для CPU и RAM в статусной строке;
- терминал с поддержкой True Color — для корректных цветов.

Проверить версию:

```bash
tmux -V
```

## Быстрая шпаргалка

Префикс — `Ctrl+a` (далее `C-a`). После префикса нажмите указанную клавишу.

| Комбинация | Действие |
|---|---|
| `C-a r` | Перечитать конфиг |
| `C-a =` | Разделить панель вертикально (рядом) |
| `C-a -` | Разделить панель горизонтально (друг под другом) |
| `C-a x` | Закрыть панель с подтверждением (стандартная tmux) |
| `C-a z` | Развернуть/свернуть панель (стандартная tmux) |
| `C-a S` | Включить/выключить синхронизацию ввода во все панели |
| `Alt+1`…`Alt+9` | Перейти на окно или создать его |
| `Alt+q` | Закрыть окно с подтверждением |
| `Alt+e` | Закрыть панель без подтверждения |
| `C-a c` | Новое окно в текущем каталоге |
| `C-a ,` | Переименовать окно (стандартная tmux) |
| `C-a d` | Отключиться от сессии (сессия остаётся) |
| `C-a s` | Список сессий (стандартная tmux) |
| `C-a $` | Переименовать сессию (стандартная tmux) |
| `C-a [` | Войти в режим копирования |
| `C-a ]` | Вставить из буфера tmux |
| `C-a h` | Всплывающая шпаргалка |
| `C-a ?` | Полный список клавиш tmux (стандартная tmux) |
| `C-a t` | Часы (стандартная tmux) |

## Основы

- Префикс заменён с `Ctrl+b` на `Ctrl+a`; `Ctrl+b` отвязан.
- `C-a C-a` отправляет префикс во вложенное приложение (например, в
  приложение, которое само использует `Ctrl+a`).
- `C-a r` перечитывает `~/.tmux.conf`; сообщение «Конфиг перезагружен»
  появляется в статусной строке.
- `default-terminal` — `xterm-256color`, True Color включён через
  `terminal-overrides ",xterm-256color:Tc"`.
- История скролла — 10 000 строк (`history-limit`).
- Окна и панели нумеруются с 1 (`base-index`, `pane-base-index`).
- После закрытия окна номера сжимаются (`renumber-windows on`).
- `escape-time 10` уменьшает задержку Esc — удобнее для vim и nano.
- Мышь включена: клик выбирает панель/окно, колесо прокручивает историю.
- `focus-events on` — приложения получают события фокуса.

## Панели

- `C-a =` — разделить вертикально (панели рядом), в текущем каталоге.
- `C-a -` — разделить горизонтально (панели друг под другом), в текущем
  каталоге.
- Стандартные `C-a "` и `C-a %` отвязаны: используйте `=` и `-`.
- `C-a x` — закрыть панель с подтверждением (стандартная tmux).
- `Alt+e` — закрыть панель без подтверждения.
- `C-a z` — развернуть панель на весь экран и вернуть обратно (стандартная
  tmux).
- `C-a S` — синхронизация ввода. Когда режим включён, команда, введённая в
  одной панели, выполняется во всех панелях окна; в статусе отображается
  `⚡SYNC`.

Vim-навигация (`h/j/k/l`) и изменение размера (`H/J/K/L`) в конфиге
закомментированы: `C-a h` занят всплывающей справкой. Как включить — см.
раздел «Личные настройки».

## Окна

- `Alt+1`…`Alt+9` — перейти на окно с этим номером. Если окна нет, оно
  создаётся. Это `bind -n`, префикс не нужен.
- `Alt+q` — закрыть текущее окно с подтверждением.
- `C-a c` — новое окно в каталоге текущей панели (не в домашнем по умолчанию).
- `C-a ,` — переименовать окно (стандартная tmux).
- `C-a n` / `C-a p` — следующее/предыдущее окно (стандартные tmux).
- Автопереименование включено: если в панели работает оболочка, окно
  называется по команде; если приложение меняет заголовок — по заголовку.
- Окно с активностью подсвечивается оранжевым, с bell — красным.

## Сессии

- `C-a d` — отключиться; сессия и процессы продолжают работать.
- `C-a s` — список сессий.
- `C-a $` — переименовать сессию.
- `C-a (` / `C-a )` — предыдущая/следующая сессия (стандартные tmux).

Автозапуск tmux при входе по SSH и на `ttyS0` настраивается в `~/.bashrc`, а не
в `.tmux.conf`. Для создания сессии используется `tmux new-session -e`, поэтому
требуется tmux 3.2+.

## Копирование и буфер

- `C-a [` — режим копирования; включён vi-режим (`mode-keys vi`).
- `v` — начать выделение.
- `y` — скопировать выделенное и выйти из режима.
- `C-a ]` — вставить из буфера tmux.
- Мышь также работает: выделение мышью и прокрутка колесом.

Буфер tmux — **не системный буфер обмена**. Для интеграции с системным
буфером нужны отдельные настройки (`set-clipboard`, OSC 52 или `xclip`); в
этом конфиге их нет.

## Статусная строка

Статусная строка занимает две строки внизу, обновляется каждые 2 секунды.

Верхняя строка:

- имя сессии; для root — красная плашка `ROOT:<сессия>`;
- список окон: номер, имя, флаги;
- активное окно — бирюзовое;
- окно с активностью — оранжевое;
- окно с bell — красное;
- если в заголовке панели есть `root`, окно подсвечивается красным.

Нижняя строка:

- hostname (`#H`);
- текущий каталог панели;
- `⚡SYNC`, если включена синхронизация;
- CPU — по `vmstat`;
- RAM — по `free -m`;
- load average — из `/proc/loadavg`;
- дата и время.

Если CPU/RAM не отображаются, установите `procps`:

```bash
apt-get install -y procps
```

## Уведомления

- Звуковых сигналов нет: `visual-bell on`.
- `monitor-activity on` и `visual-activity on` — вывод в фоновом окне
  подсвечивает окно и показывает сообщение.
- `monitor-silence 30` — окно, в котором 30 секунд нет вывода, помечается.
- `bell-action other` — bell реагирует только на фоновые окна.

Отключить уведомления в `~/.tmux.local.conf`:

```tmux
setw -g monitor-activity off
setw -g monitor-silence 0
```

## Всплывающая справка

`C-a h` открывает popup 64×32 с краткими горячими клавишами. Закрывается
любой клавишей. Требует tmux 3.2+ (`display-popup`).

## Личные настройки

Личный файл — `~/.tmux.local.conf`; он подключается в конце и переопределяет
общие настройки. Примеры:

```tmux
# Отключить уведомления
setw -g monitor-activity off
setw -g monitor-silence 0

# Отключить мышь
set -g mouse off

# Другой префикс
unbind C-a
set -g prefix C-Space
bind C-Space send-prefix

# Включить vim-навигацию по панелям.
# C-a h занят справкой: переназначьте её, если нужна навигация на h.
bind h select-pane -L
bind j select-pane -D
bind k select-pane -U
bind l select-pane -R
bind -r H resize-pane -L 5
bind -r J resize-pane -D 5
bind -r K resize-pane -U 5
bind -r L resize-pane -R 5
```

После правки: `C-a r` или

```bash
tmux source-file ~/.tmux.conf
```

## Отличия от стандартного tmux

- Префикс `C-a` вместо `C-b`.
- Разделение панелей `=` и `-` вместо `"` и `%`.
- `C-a c` создаёт окно в текущем каталоге.
- `C-a h` — справка (перекрывает стандартную навигацию влево, если её
  включить).
- `C-a S` — синхронизация панелей с индикатором `⚡SYNC`.
- `Alt+1…9`, `Alt+q`, `Alt+e` — без префикса.
- Vi-режим копирования.
- Двухстрочный статус с ресурсами, выделением root и уведомлениями.
- Vim-навигация и resize закомментированы.

## Диагностика

**`unknown command: display-popup` или `new-session -e`.** tmux старше 3.2.
Проверьте `tmux -V` и обновите пакет.

**Конфиг не применяется.** Перечитайте его (`C-a r` или
`tmux source-file ~/.tmux.conf`) и посмотрите сообщение об ошибке. Проверить
значение опции: `tmux show-options -g <option>`.

**Нет True Color.** Проверьте терминал и tmux:

```bash
echo "$TERM"
tmux info | grep -i Tc
```

**Alt-клавиши не работают.** Терминал должен отправлять Meta для Alt. В
macOS Terminal включите «Use Option as Meta».

**Не работает мышь.** Проверьте `tmux show-options -g mouse`; должно быть
`mouse on`. Некоторые терминалы перехватывают прокрутку.

**Пустые CPU/RAM.** Установите `procps`; проверьте `vmstat 1 2` и `free -m`.

**Статус не обновляется.** `status-interval` равен 2; проверьте
`tmux show-options -g status-interval`.

**Изменили `~/.tmux.conf`, а настройки вернулись.** Установщик перезаписывает
этот файл при обновлении. Личные настройки держите в `~/.tmux.local.conf`.
